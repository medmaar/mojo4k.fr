Downloader IPTV : à quoi sert cette application ?

Downloader est éditée par AFTVnews, un site spécialisé dans les appareils Fire TV. Elle ne contient aucune chaîne et n'a rien d'illégal : c'est un outil, au même titre qu'un navigateur. Son intérêt sur une clé Amazon est double : elle télécharge les fichiers d'installation Android (APK) et elle se pilote facilement à la télécommande.

Pourquoi en a-t-on besoin ? Parce que plusieurs lecteurs populaires, comme IPTV Smarters Pro ou TiviMate, ne sont pas proposés dans l'Amazon Appstore en France. Leurs éditeurs les distribuent sur leur propre site ou sur Google Play, et Downloader fait le lien.

💡 Vérifiez d'abord votre modèle

Downloader ne sert qu'aux clés sous Fire OS, le système dérivé d'Android. Les modèles récents qui tournent sous Vega OS, le nouveau système d'Amazon, n'installent pas d'applications Android hors de l'Appstore. Avant d'acheter une clé pour l'IPTV, vérifiez le système indiqué sur la fiche produit ; sinon, un lecteur présent dans l'Appstore ou une clé Google TV sera nécessaire.

Installer un lecteur IPTV avec Downloader, étape par étape

1

Installer Downloader

Depuis l'accueil de la Fire TV, ouvrez la recherche, tapez « Downloader » et installez l'application à l'icône orange éditée par AFTVnews.

2

Débloquer les options pour les développeurs

Paramètres → Ma Fire TV → À propos : cliquez sept fois sur le nom de votre appareil. Un message confirme que les options pour les développeurs sont activées.

3

Autoriser Downloader à installer des applis

Paramètres → Ma Fire TV → Options pour les développeurs → Installer des applis inconnues → activez Downloader. Sur les versions plus anciennes, l'option s'appelle « Applis de sources inconnues ».

4

Saisir l'adresse officielle du lecteur

Ouvrez Downloader et tapez dans le champ d'adresse le site officiel de l'éditeur (par exemple iptvsmarters.com pour Smarters). Choisissez la version Android ou Fire TV sur la page de téléchargement.

5

Installer puis nettoyer

Validez l'installation. Downloader propose ensuite de supprimer le fichier APK : acceptez, cela libère de l'espace sur une clé qui en a peu.

6

Se connecter à votre abonnement

Ouvrez le lecteur depuis Vos applis, choisissez la connexion Xtream Codes et saisissez l'URL du serveur, l'identifiant et le mot de passe reçus.

Les « codes Downloader » : prudence

Downloader permet de saisir un code numérique court à la place d'une adresse : il renvoie vers un lien enregistré par quelqu'un, via le service de raccourcis d'AFTVnews. N'importe qui peut créer un code, et rien ne garantit que le fichier visé soit celui de l'éditeur. C'est pourquoi nous ne publions aucun code sur cette page.

  • Préférez toujours l'adresse complète du site officiel de l'éditeur
  • Méfiez-vous des vidéos qui donnent un code menant à une application « tout compris » avec chaînes intégrées
  • Si le lecteur existe sur Google Play ou dans l'Appstore, installez-le de là plutôt que par un fichier
  • Ne transmettez jamais vos identifiants IPTV à une application dont vous ignorez l'origine

Pour reconnaître les applications et offres douteuses, consultez notre page arnaques IPTV.

Optimiser la clé Amazon pour l'IPTV

Une fois le lecteur installé, quelques réglages améliorent nettement la fluidité de l'IPTV sur Fire Stick :

  • Branchez la clé sur son adaptateur secteur, pas sur le port USB de la TV
  • Utilisez le Wi-Fi 5 GHz ou un adaptateur Ethernet compatible Fire TV
  • Désinstallez les applications inutiles : l'espace de stockage est limité
  • Désactivez la lecture automatique des vidéos de l'accueil dans les paramètres de préférences

Notre guide complet installer l'IPTV sur Fire Stick couvre aussi le choix entre les modèles. Avec MOJO 4K, vous recevez vos identifiants Xtream Codes et votre lien M3U sur WhatsApp, et l'essai gratuit de 24h permet de vérifier que tout fonctionne sur votre clé.

Avant d'installer quoi que ce soit, mesurez votre connexion réelle avec un test de débit nPerf : au moins 10 Mb/s pour la HD et 25 Mb/s pour la 4K.

Questions fréquentes

L'application Downloader est-elle légale ? +
Oui. Downloader est un outil gratuit édité par AFTVnews et disponible dans l'Amazon Appstore. Elle télécharge des fichiers comme un navigateur. La légalité dépend uniquement du contenu que vous installez et regardez ensuite.
Quel code Downloader utiliser pour IPTV Smarters ? +
Nous ne recommandons aucun code : ils peuvent renvoyer vers n'importe quel fichier. Tapez plutôt l'adresse du site officiel de l'éditeur, iptvsmarters.com, et choisissez la version Android ou Fire TV dans la page de téléchargement.
Je ne trouve pas les options pour les développeurs, que faire ? +
Allez dans Paramètres, Ma Fire TV, À propos, puis cliquez sept fois sur le nom de votre appareil. Le menu Options pour les développeurs apparaît alors dans Ma Fire TV.
Downloader fonctionne-t-il sur toutes les clés Amazon ? +
Sur les modèles sous Fire OS, oui. Les modèles récents sous Vega OS n'acceptent pas les applications Android installées manuellement. Vérifiez le système de votre clé dans les paramètres ou sur sa fiche produit.
Downloader existe-t-il sur Google TV ? +
Oui, Downloader est aussi proposé sur le Play Store des appareils Android TV et Google TV. Sur ces appareils, vérifiez d'abord si votre lecteur IPTV est disponible directement sur Google Play.
Faut-il garder Downloader après l'installation ? +
Ce n'est pas obligatoire, mais c'est pratique pour installer une mise à jour du lecteur plus tard. Supprimez en revanche les fichiers APK téléchargés pour libérer de l'espace de stockage.
